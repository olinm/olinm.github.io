# Oliwia's research website

Static personal research website for `olinm.github.io`, including permanent resources for the venous-organoids project.

## Publish

Upload everything in this folder to the root of the `olinm/olinm.github.io` repository. Preserve the `assets` and `resources` folders. Then open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, and save.

Wait for GitHub to confirm that the site is live before generating QR codes.

Permanent resource links:

- `https://olinm.github.io/resources/venous-organoids/#live-cell-imaging`
- `https://olinm.github.io/resources/venous-organoids/#quantification-walkthrough`
- `https://olinm.github.io/resources/venous-organoids/#additional-resources`

Do not rename the `resources/venous-organoids` folders or the three section IDs after printing the QR codes.
